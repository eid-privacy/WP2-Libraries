**Repository**: https://github.com/arkworks-rs/crypto-primitives
**Language:** Rust
**License**: MIT and Apache-2.0

**Features:**

- Collision-resistant hash functions
- Hiding commitments
- Pseudo-random functions
- Signatures
- R1CS constraints for cryptographic primitives
- Merkle trees
- Blake2s hash function
- Poseidon sponge function
- Schnorr signatures

**Additional Information:**

- Part of arkworks ecosystem for zkSNARKs
- Academic proof-of-concept prototype
- Requires Rust stable toolchain
- 99.7% Rust, 0.3% Python
