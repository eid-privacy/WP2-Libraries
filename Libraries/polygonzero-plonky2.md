**Repository**: https://github.com/0xPolygonZero/plonky2
**Language:** Rust
**License**: MIT and Apache-2.0

**Features:**

- Plonky2 SNARK implementation (PLONK + FRI)
- Starky - highly performant STARK implementation
- Recursive zero-knowledge proofs

**Additional Information:**

- Originally focused on Plonky2, expanded to include Starky
- Requires nightly Rust toolchain
- Supports Jemalloc memory allocator
- Targets 100 bits of security
- Uses Poseidon hash function by default
- Code audited prior to v1.0.0 release
