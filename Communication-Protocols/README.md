# Communication Protocols
In each of the files in this directory, you find a list of libraries that implement a specific communication protocol.  
These communication protocols specify a way for issuers/verifiers/holders to communicate with each other within the 
Self-Sovereign Identities eco-system.

Current protocols considered:

- [OpenID4VC](./OpenID4VC.md)
- [DIDComm](./DIDComm.md)
